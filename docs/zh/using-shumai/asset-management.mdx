Shumai 支持便捷地将创意媒体素材导入工作区，按文件夹分类整理，并全流程管理从上传到删除的完整资产生命周期。

---

## 上传资产

可以通过以下三种方式将文件和文件夹上传至 Shumai：

1. **拖拽上传**：从电脑的文件管理器中直接拖拽文件或整个文件夹，释放到 Shumai 控制台界面的任意位置。
2. **按钮上传**：点击工具栏中的 **上传文件** 或 **上传文件夹** 按钮。
3. **复制粘贴**：从其他网站、应用程序或剪贴板复制图片或文件，直接在 Shumai 浏览器窗口中粘贴（`Ctrl+V` 或 `Cmd+V`）即可立即上传。

## 文件夹组织

上传整个文件夹时，Shumai 会在项目中完整保留并重建原始文件夹层级结构：

- 自动创建所有子文件夹。
- 嵌套文件保留在各自对应的子文件夹中。
- 支持任意深度的文件夹层级嵌套上传。

---

## 上传与处理状态

上传启动后，资产将历经以下几种状态：

- **上传中（Uploading）**：文件正在传输到存储服务器，界面实时显示传输进度百分比。
- **处理中（Processing）**：文件已成功上传。Shumai 正在提取媒体参数（如分辨率、视频时长和音频编解码器）并生成便于 Web 在线流畅播放的预览代理（Proxy）。
- **就绪（Ready）**：处理完毕。资产已完全可见、支持在线播放，并可随时添加评论、标记元数据或搜索。

## 删除与恢复资产

若某些资产不再需要，可以将其删除以整理工作区：

### 回收站（最近删除）

- 删除文件或文件夹后，相应资产将移至项目设置中的 **最近删除**（Recently Deleted）标签页。
- 已删除资产会在回收站中保留 **30 天**。在此期间，可选中任意资产并点击 **恢复**（Recover）将其还原至原始位置。
- 若需立即释放存储空间，可打开“最近删除”标签页并点击 **清空回收站**（Empty Trash）永久清除文件。

### 永久删除

在回收站保留 **30 天** 后，资产将自动永久清除。清除完成后，相关记录会从数据库中移除，文件也会从存储后端（本地文件系统或 S3 存储桶）彻底删除且无法恢复。
