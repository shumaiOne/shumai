创建用于对话或元数据自动填充的智能体时，需要选择底层的 AI 模型。可用模型与服务商在团队设置中集中统一配置。

> 🔒 **权限说明：** 仅**团队所有者（Team Owner）**拥有管理 AI 模型服务商的权限。若需调整配置，请点击头像进入**设置**，并在左侧导航栏中选择**服务商（Providers）**。

---

## 内置模型服务商

Shumai 预置了主流 LLM 服务商的配置。由于 Shumai 采用 [Pi](https://github.com/earendil-works/pi) 作为底层核心智能体框架，系统支持的服务商与模型配置会自动与 Pi 的功能生态保持同步。

团队所有者可自由编辑、删除或添加新服务商。所有已配置的服务商与模型参数均会在运行时直接注入 Pi 框架。

## 配置参考

### 服务商配置项

配置服务商时需指定以下字段：

| 字段                            | 说明                                 | 示例 / 备注                                                                                   |
| :------------------------------ | :----------------------------------- | :-------------------------------------------------------------------------------------------- |
| **服务商名称（Provider Name）** | 唯一且易于辨识的服务商标识。         | `Ollama-Local`、`Enterprise-Gateway`                                                          |
| **基础 URL（Base URL）**        | 目标 API 端点地址。                  | `http://localhost:11434/v1`                                                                   |
| **API 协议（API Protocol）**    | 流式传输与请求载荷协议格式。         | 大多数兼容 OpenAI 的网关使用 `openai-completions`。                                           |
| **API 密钥（API Key）**         | 身份认证令牌。本地无鉴权环境可留空。 | 支持直接填入密钥明文（`sk-...`），或指定宿主机环境变量名称（如 `MY_API_KEY`）以安全读取凭据。 |

### 模型配置项

每个服务商下均可挂载多个模型。每个模型支持配置以下属性：

| 字段                                    | 说明                                                  | 示例 / 备注                            |
| :-------------------------------------- | :---------------------------------------------------- | :------------------------------------- |
| **模型 ID（Model ID）**                 | 上游 API 所要求的精确模型标识符。                     | `gpt-4o`、`claude-3-5-sonnet-20240620` |
| **显示名称（Display Name）**            | 下拉菜单中面向用户展示的自定义友好名称（可选）。      | `GPT-4 Omni`、`Claude 3.5`             |
| **深度推理支持（Reasoning Support）**   | 开关选项，用于启用深度思考（Extended Thinking）协议。 | 适用于具备原生推理能力的模型。         |
| **上下文窗口（Context Window）**        | 模型支持的最大 Token 总容量（输入 + 输出）。          |                                        |
| **最大输出 Token（Max Output Tokens）** | 单次请求生成回复的 Token 上限。                       |                                        |
| **输入成本（Input Cost）**              | 每百万输入 Token 的单价。                             | 可选，用于统计使用开销与用量指标。     |
| **输出成本（Output Cost）**             | 每百万输出 Token 的单价。                             | 可选，用于统计使用开销与用量指标。     |
