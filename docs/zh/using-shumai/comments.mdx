Shumai 专为音视频及图像反馈打造了沉浸式审阅工作区。除了常规文字评论外，团队成员还可以添加精确到时间戳的反馈，并直接在画面上绘制标注涂鸦。

---

## 时间戳评论

审阅音视频文件时，可以将评论锚定在时间轴上的精确秒数或关键帧：

1. 播放或拖动进度条定位到需要审阅的精准画面帧或时间点。
2. 在评论输入框中输入反馈意见。
3. 点击 **发送**（Submit）。评论将连同时间标记一同保存，并在视频时间轴上生成标记锚点。
4. 协作者点击侧边栏中的评论卡片，播放器即可直接跳转至对应的时间点。

## 画面标注（画布涂鸦）

为了提供清晰直观的视觉反馈，可以直接在图片或视频画面帧上绘制标注：

1. 将视频暂停在需要标注的画面帧。
2. 在播放器上方的标注工具栏中选择绘图工具（画笔、矩形、圆形、箭头等）。
3. 直接在画面屏幕上绘制标注。
4. 输入评论并点击 **发送**（Submit）。绘制的标注涂鸦将与该条评论绑定保存。
5. 当其他成员选择该条评论时，播放器将在对应帧画面上自动叠加显示绘制的标注。

![画面标注](/draw_annotation.webp)

---

## 评论会话（回复）

通过直接回复反馈保持讨论条理清晰：

- 点击任意评论下方的 **回复**（Reply）。
- 回复内容将按层级嵌套在主评论卡片下，方便跟踪问题讨论与解决进展。

---

## 附件

可以在评论中附加参考文档、设计规范或其他资产：

- 点击评论输入框内的 **回形针**（Paperclip）图标。
- 选择要上传的文件。上传后将作为可直接下载的链接显示在评论卡片中。
