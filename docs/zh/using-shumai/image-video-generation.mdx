title: 图像与视频生成
description: 为内置 AI 智能体工具配置图像与视频生成服务商及模型。
---

Shumai 智能体可通过内置工具——**生成图像**（`generate_image`）与**生成视频**（`generate_video`），在工作区中直接生成创意视觉资产。

生成视觉媒体资产需要专用的多模态基座模型支持。智能体调用这些能力前，团队所有者必须先在团队设置中配置上游服务商并启用对应模型。

> 🔒 **权限说明：** 仅**团队所有者（Team Owner）**拥有查看与配置媒体生成设置的权限。请点击头像进入**设置**，在左侧导航栏选择**图像/视频生成**（或直接访问 `teams/<teamId>/settings#image-video`）。

---

## 为何需要此项配置

在 **AI 服务商**中配置的对话类模型主要负责文本推理与对话交互；而图像与视频生成则依赖专用的多模态生成模型（如 DALL-E、FLUX、Gemini Image、Veo、可灵 Kling AI、Luma Ray、万象 Wan 等）。

**图像/视频生成**配置页面支持团队所有者：

1. 接入并认证一个或多个受支持的图像与视频生成服务商。
2. 选择为团队启用精选推荐模型，或注册自定义模型 ID。
3. 设定智能体生成视觉资产时的默认模型。

---

## 工具可用性与激活规则

<Warning>
  **重要提示：** 仅在智能体配置弹窗中勾选 `generate_image` 或 `generate_video`
  还**远远不够**。只有同时满足以下三项条件，智能体才能真正调用该工具：
</Warning>

1. **服务商已配置：** 对应服务商已配置有效 API 密钥（通过服务端环境变量注入，或在团队设置中配置了自定义团队密钥）。
2. **至少启用了一个模型：** 在已激活的服务商下，对应模态（`image` 或 `video`）**至少启用了一个模型**。
3. **已向智能体开放工具权限：** 在**团队设置** > **智能体** > **工具**权限列表中，该工具未被禁用。

### 未配置模型时的系统行为

若已配置的服务商下未启用任何图像模型，`generate_image` 工具将从智能体的运行时环境中**彻底移除**。同理，若未启用任何视频模型，`generate_video` 工具亦会被移除。

在此状态下：

- 智能体**无法调用**该生成工具。
- 该工具不会出现在智能体的工具目录或 Prompt 提示词定义中。
- 即便团队所有者在智能体设置弹窗中开启了**生成图像**或**生成视频**开关，只要未启用模型，智能体仍旧无法使用该工具。

## 配置服务商与 API 密钥

在**媒体服务商**列表中点击任意服务商，即可打开其配置弹窗：

### 服务商状态说明

- **已配置 (自定义)**：在此弹窗中填入了团队专属的 API 密钥或自定义环境变量名。
- **已配置 (环境变量)**：系统检测到了服务端配置的默认环境变量（如 `OPENAI_API_KEY`）。除非需要覆盖该默认值，否则无需另行配置团队密钥。
- **未配置**：未检测到可用 API 密钥。使用此服务商前必须提供 API 密钥或环境变量名。

### 覆盖 API 密钥

在服务商弹窗的 **API Key** 标签页中：

- 输入 API 密钥明文（如 `sk-...`），或填入宿主机系统中已定义的环境变量名称。
- 点击**清除自定义密钥**，即可恢复使用服务端默认环境变量（若存在）。

## 管理模型

在服务商配置弹窗的 **Models** 标签页中：

### 精选模型

Shumai 预置了主流的精选推荐模型（如 `dall-e-3`、`fal-ai/flux/dev`、`veo-3.1-generate`、`kling-v3.0-t2v` 等）。切换模型旁边的开关，即可为团队启用或禁用该模型。

### 自定义模型

若服务商上线了新模型或支持微调模型，且未收录在精选列表中：

1. 选择模态（**图像**或**视频**）。
2. 输入上游服务商所要求的准确 **Model ID**。
3. 点击**添加**。

### 默认模型选择机制

每种类型（`image` 或 `video`）中**首个启用的模型**将自动成为默认模型。当智能体调用 `generate_image` 或 `generate_video` 且未显式指定 `model` 参数时，Shumai 会自动将生成请求路由至该默认模型。

## 智能体如何使用生成工具

启用之后，智能体便可在对话或自动化工作流中调用相关工具：

### 1. 生成图像 (`generate_image`)

- **提示词（Prompt）：** 图像的详细文本描述。
- **模型选择：** 默认使用首个已启用的图像模型；智能体亦可按 `provider:modelId` 格式（如 `openai:dall-e-3` 或 `fal:fal-ai/flux/dev`）选用任意已启用模型。
- **参考图输入：** 智能体可通过 `read_asset` 工具获取工作区已有资产的 S3 存储键（`s3KeyOnly: true`），并将其作为画面风格或构图参考。
- **局部重绘（Inpainting）：** 支持传入 S3 蒙版键，实现基于遮罩的局部精准重绘。
- **控制参数：** 支持自定义宽高比（`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`2:3`、`3:2`）、分辨率尺寸及随机种子（Seed）。

### 2. 生成视频 (`generate_video`)

- **生成模式：**
  - `text_to_video`：根据动态文本提示词生成视频片段。
  - `image_to_video`：将工作区已有静态图片转化为动态视频。
  - `first_last_frame`：在首尾两帧资产之间生成流畅自然的过渡插帧。
  - `reference_to_video`：基于参考图生成视频，保持角色形象或场景环境的一致性。
- **控制参数：** 支持设置宽高比（`16:9`、`9:16`、`1:1`、`adaptive`）、分辨率、时长、帧率（FPS）以及音效生成开关。

### 资产生成入库流程

所有生成的媒体文件起初均保存在本地沙箱目录（`.pi/`）中。随后，智能体可调用**创建文件**（`create_file`）将生成结果作为新资产上传至项目中，或调用**创建版本**（`create_version`）将其追加至已有资产的版本历史中。
