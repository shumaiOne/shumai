原生 AI 模型通常仅具备文本与图像处理能力。在 Shumai 中，可通过注册**技能（Skills）**为**对话智能体**与**自动填充智能体**扩展能力边界——技能即智能体在执行任务时可调用的自定义脚本。

---

## 技能运作机制

技能由用户自行定义，并授权给 AI 智能体使用。

- **面向 AI 的元数据描述**：注册技能后，AI 智能体会读取其元数据描述，理解在何种场景下、以何种方式调用该工具来解决具体问题。
- **执行与本地缓存**：当智能体决定调用某项技能时，Shumai 会负责调度执行。新添加的技能数据首先同步至数据库；执行时，智能体会从数据库下载并在本地缓存技能文件，确保高效稳定的访问速度。

---

## 添加技能

向 Shumai 安装新技能的步骤如下：

1. 前往**设置**页面并切换至**技能（Skills）**标签页。
2. 点击**添加技能**按钮。
3. 在弹出的对话框中选择安装方式：
   - **本地上传**：选择并上传包含技能文件的 `.zip` 压缩包。
   - **GitHub 导入**：填入合法的 GitHub 仓库路径。

> **重要提示：** 无论采用哪种安装方式，技能包根目录下必须包含 `SKILL.md` 文件。

### 更新现有技能

若需更新技能，只需按上述步骤重新安装新版本，并保持技能名称完全一致，Shumai 便会自动覆盖旧版本。

---

## 配置环境变量

若自定义技能依赖环境变量（如 API 密钥、外部 Token）才能运行：

1. 在技能列表中点击已安装的**技能卡片**打开配置弹窗。
2. 添加所需的环境变量。
3. _（可选）_ 为环境变量设定默认值。若未指定默认值，技能将在运行时动态读取宿主机系统环境变量。

---

## 为智能体启用技能

**所有技能默认均处于禁用状态。** 仅安装技能并不会赋予智能体调用权限。若需授权智能体调用已安装的技能：

1. 前往对应的**智能体设置**。
2. 勾选希望授权给该智能体的技能。
