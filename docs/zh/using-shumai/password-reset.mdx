---
title: 密码重置
description: 管理员如何为团队成员生成安全的密码重置链接。
---

考虑到标准私有化部署下 Shumai 并未强制要求配置外部邮件服务（SMTP），密码重置操作由管理员通过 Shumai CLI 安全发起。

---

## 概述

当用户遗忘密码时，管理员可直接在命令行中为其生成一次性密码重置链接。

- **链接有效期**：生成的密码重置链接有效期为 **1 小时**（`3600 秒`）。
- **一次性使用**：重置令牌一经使用即刻永久失效。
- **会话注销**：用户重置密码后，该账户在所有设备上的所有现有活跃会话均会自动注销。
- **最新链接有效原则**：为同一用户生成新的重置链接后，此前生成的所有待处理链接立即失效。

---

## 生成密码重置链接

### 在本地宿主机 / 服务器运行

在 Shumai 安装目录下运行 `reset-password` 子命令：

```bash
shumai reset-password <user-email>
```

_(或执行 `bun apps/web/src/index.ts reset-password <user-email>`)_

**输出示例：**

```text
http://localhost:3000/reset-password?token=bb3xg4uO3cwN0FQv4cgUK6Hh
```

### 在 Docker 容器内运行

若 Shumai 运行在 Docker 容器中，请使用 `docker exec` 执行命令：

```bash
docker exec -it <container-name-or-id> shumai reset-password <user-email>
```

> [!TIP]
> 系统同时支持 `shumai` 与常见易错拼写别名 `shuami`（例如 `shuami reset-password <user-email>`）。

> [!NOTE]
> 对于远程服务器或生产环境部署，请确保环境中已配置 `BETTER_AUTH_URL`（例如 `BETTER_AUTH_URL=https://shumai.example.com`），以便 CLI 生成带有公网域名的重置链接，而非 `localhost`。

---

## 成员重置流程

1. 管理员通过安全的沟通渠道将生成的 URL 发送给团队成员。
2. 用户在浏览器中打开该链接。
3. 用户输入 **新密码** 并 **确认密码**（长度至少 3 个字符）。
4. 点击 **重置密码** 后，密码即安全更新，所有旧的活跃会话全部失效，并跳转至 `/login` 页面重新登录。
