随着项目规模扩大，快速检索所需的媒体文件至关重要。Shumai 提供了功能强大的搜索对话框与灵活的排序控件。

---

## 搜索资产

点击工具栏中的搜索图标，即可打开专用的 **搜索对话框**。

![搜索对话框](/search-dialog.webp)

### 搜索对话框特性

- **关键词匹配**：在文本输入框中输入关键词，即可即时过滤文件名和文件夹名。
- **高级筛选**：点击展开筛选面板，构建多条件复合查询（例如：查找自定义字段“状态”等于“处理中”且文件类型为“视频”的文件）。
- **语义搜索开关**：若团队管理员启用了该功能，开启“语义搜索”（Semantic）开关即可按概念含义搜索（例如：搜索“阳光海滩”即可找到海洋片段，即使文件名中并未包含这些词）。
- **保存为合集**：便捷地将当前搜索条件转化为动态合集。点击对话框内的 **保存为合集**（Save as Collection），即可创建该合集并直接跳转至对应视图。
- **无限滚动加载**：输入关键词或调整筛选条件时，搜索结果将实时动态加载。

## 资产排序与重排

可以通过排序下拉菜单或点击元数据列标题，切换资产列表的排序规则：

- **自定义排序（默认）**：项目文件管理器默认采用 **自定义**（Custom）排序。在此模式下，可直接通过手动拖拽文件与文件夹，按需排列显示顺序。
- **标准排序选项**：支持按以下维度排序：
  - _最新上传_：优先展示最新上传的资产。
  - _名称_：按字母顺序排列（A-Z 或 Z-A）。
  - _大小_：按文件体积大小排序。
  - _类型_：将文件夹置顶聚合，随后展示版本堆栈与单文件。
  - _自定义列_：按动态元数据字段排序（例如：按“截止日期”或“优先级”排序）。

> [!NOTE]
> **拖拽重排限制**：仅当排序规则设置为 **自定义** 时，才支持手动拖拽调整顺序。若选择了其他排序选项（如按名称或大小），手动重排功能将自动禁用。
