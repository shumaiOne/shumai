Standard file systems restrict you to basic properties like file size and modified dates. Shumai allows you to create custom fields tailored to your production pipeline.

---

## Metadata Scopes

Custom fields can be defined at different scopes:

- **System Scope**: Universal fields defined by system administrators that appear across all teams and projects.
- **Team Scope**: Fields inherited by all projects within a team. Useful for maintaining company-wide tagging or department standards.
- **Project Scope**: Custom fields restricted to a single project workspace.

---

## Custom Field Types

When creating a new field, you can choose from the following data types:

- **Text (String)**: For simple text, descriptions, tags, or status labels.
- **Number**: For numeric values (e.g. frame rates, rating scores, review passes).
- **Yes/No (Boolean)**: Simple toggles (e.g. `Approved`, `VFX Required`).
- **Date**: Calendar selection (e.g. `Due Date`, `Launch Date`).

---

## Field Settings

### Read-Only

When enabled, standard team members cannot edit the field value through the dashboard interface. This is ideal for fields populated automatically by background tasks (like video resolution, audio formats, or AI confidence scores).

### AI Autofill

If a field is flagged for **AI Autofill**, Shumai's background worker will automatically analyze the asset contents using the team's default Gemini model upon upload.

- For video/images: The AI analyzes the visuals to suggest tags, write description summaries, or classify content themes.
- The metadata values are updated automatically once the asset is ready.
