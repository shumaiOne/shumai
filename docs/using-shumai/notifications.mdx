Shumai includes a built-in notification system to keep you informed of team activities, file statuses, and review comments.

---

## What Triggers a Notification?

You will receive notifications for the following events:

- **New Comments**: When a collaborator comments on an asset you created or are watching.
- **Thread Replies**: When someone replies directly to a comment thread you participated in.
- **Direct @Mentions**: Sent immediately if someone tags you (using `@username`) in any comment.
- **Upload Finished**: Sent when a file you uploaded is finished transcoding and is ready for review.
- **Status Changes**: Sent if a critical metadata field (like a file's "Approval Status") is updated.
- **New Members**: Notifies project owners when a new collaborator joins their project via invite link.

---

## Project-Level Notification Toggles

If you are working in a highly active project and want to reduce noise, you can disable notifications for that project:

1.  Navigate to **Project Settings**.
2.  Locate the **Enable Notifications** toggle.
3.  Turn it off. You will stop receiving updates for file uploads and standard comments in this project, but direct `@mentions` will still be delivered to your inbox.

---

## The Notification Inbox

- The **Bell** icon in the navigation bar displays a red badge when you have unread notifications.
- Click the bell to open your inbox panel.
- Clicking any notification card will mark it as read and take you directly to the relevant file and comment thread.
