Shumai includes a built-in notification system to keep you informed of team activities, file statuses, and review comments.

---

## Notification Types

The following actions trigger system notifications:

- **Comment Created**: Triggered when a new comment is posted on an asset you created or are watching.
- **Reply Created**: Triggered when someone replies directly to a comment thread you participated in.
- **Mentions**: Sent immediately if a collaborator tags you (using `@username`) in any comment.
- **Upload Complete**: Sent when a file you uploaded transitions from the `processing` state to `processed`.
- **Metadata Status Update**: Sent when a custom metadata field representing progress or status is modified.
- **User Joins**: Notifies owners when a new user joins the Team or Project via an invite link.

---

## Project-Level Notification Toggles

If you find yourself in a highly active project, you can toggle notifications off for that specific project:

1.  Navigate to your **Project Settings**.
2.  Locate the **Enable Notifications** toggle.
3.  Turn it off. You will stop receiving updates for file uploads and standard comments in this project, but direct `@mentions` will still be delivered to your inbox.

## The Notification Inbox

- The bell icon in the navigation bar displays a red badge when you have unread notifications.
- Clicking it opens your inbox list.
- Clicking a notification card (like a new comment) will mark it as read and redirect you directly to the relevant asset and comment thread.
