## Uploading Files and Folders

Shumai provides a seamless way to upload your assets, whether they are individual files or entire directory structures.

### How to Upload
1. Navigate to your project or folder.
2. Click the **Upload** button in the top right corner.
3. Select **Files** or **Folder** from the dropdown.
4. Drag and drop your files into the upload zone or use the file picker.

![Upload dialog showing drag and drop area](placeholder)

### Supported Formats
Shumai supports a wide range of file types, including images, videos, audio, and documents. For media files, Shumai can automatically generate previews and transcode them into web-friendly formats.

## File Version Stack

The **Version Stack** feature allows you to group multiple files together as different versions of the same asset. This is particularly useful for design iterations or video revisions.

### Creating a Version Stack
To create a version stack, select multiple files in the file explorer and click **Create Version Stack**.

### Managing Versions
- **View Versions**: Click on a version stack to see all associated versions.
- **Set Primary Version**: You can change which version is displayed as the primary asset.
- **Reorder**: Drag and drop versions to reorder them within the stack.

## Sorting and Searching

Finding your assets is easy with Shumai's robust sorting and searching capabilities.

### Search
Use the search bar at the top of the interface to find files by name or metadata. Shumai also supports **Semantic Search**, allowing you to find assets based on their content rather than just their filename (see [Semantic Search](/using-shumai/semantic-search) for more details).

### Sorting
You can sort files by:
- **Name**: Alphabetical order.
- **Date**: Sort by the date the file was added (ULID-based sorting ensure chronological accuracy).
- **Size**: Sort by file size.

### Filtering
Use the filter options to narrow down results by file type, creator, or tags.
