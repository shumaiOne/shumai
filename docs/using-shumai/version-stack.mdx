When collaborating on creative assets, files naturally go through multiple iterations (e.g. `draft_v1.mp4`, `draft_v2.mp4`, `draft_final.mp4`). To prevent workspace clutter, Shumai allows you to bundle these revisions into a **Version Stack**.

---

## What is a Version Stack?

A **Version Stack** groups multiple revisions of the same file into a single entry. Instead of cluttering your folder with several similar files, Shumai collapses them into one item with a version badge (e.g., "V3") and a dropdown list of older versions.

## Creating a Version Stack

1.  Select two or more files inside a folder using the checkboxes.
2.  Click **Create Version Stack** in the actions toolbar.
3.  The files will be bundled together into a single, clean stack.

_Note: All files grouped into a version stack must reside in the same parent folder._

---

## Managing Versions

### Active Version

The file at the top of the stack is the **Active Version**. This is the version displayed on your project dashboard, search results, and metadata panels.

### Reordering and Reverting Versions

You can promote a past version or reorder your stack:

- Open the version stack details sidebar.
- Drag and drop the versions in the list to change their order. The version you drag to the top automatically becomes the active version.
- To remove a file from the stack, drag it out or select **Unstack**. This moves the file back to the parent folder as a standalone file.
