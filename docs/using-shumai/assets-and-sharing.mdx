## Asset Metadata

Shumai allows you to attach custom metadata to your assets, making them easier to categorize and search.

### Custom Fields
Administrators can define custom metadata fields at the team or project level. Supported field types include:
- **Text**: For descriptions, notes, or short labels.
- **Select**: For predefined categories or status.
- **Number**: For quantitative data.

### AI-Powered Autofill
Some metadata fields can be configured for **AI Autofill**. When an asset is uploaded or processed, an AI Agent will automatically analyze the content and populate these fields (e.g., generating a summary or identifying keywords).

## Collections

Collections are dynamic or manual groupings of assets that span across different folders within a project.

### Creating a Collection
1. Navigate to the **Collections** tab in your project.
2. Click **Create Collection**.
3. You can either manually add assets or define a **Filter** (e.g., "All videos tagged 'Action'") to create a dynamic collection.

### Using Collections
Collections are perfect for creating "best of" lists, project mood boards, or shared review sets.

## Public Share Links

Share your assets with external collaborators or clients without requiring them to have a Shumai account.

### Creating a Share Link
1. Select one or more assets or a collection.
2. Click **Share** and select **Create Public Link**.
3. Configure sharing options:
   - **Expiration**: Set a date when the link will automatically deactivate.
   - **Permissions**: Choose whether recipients can only view or also leave comments.
   - **Password Protection**: Add an extra layer of security.

### Managing Links
You can view, update, or revoke all active share links from the **Sharing** dashboard in your project settings.
