By default, AI models can only process text. In Shumai, you can extend your agents' capabilities by registering **Skills**—custom scripts that the agent can run when solving a task.

---

## How Skills Work

Skills are actions that you define and make available to your AI agents.

- **Descriptions for the AI**: When you register a skill, you write a clear description of what the skill does. The AI agent reads this description to understand when it should use the tool.
- **Tool Execution**: When the Chat Agent decides it needs to use a skill (for example, to post a message to Slack or look up information), it requests to run that skill. Shumai executes the script in the background and returns the results to the agent.

---

## Registering a Skill

To add a new skill, navigate to **Team Settings** > **Skills**:

1.  Click **Create Skill**.
2.  Fill in the parameters:
    - **Name**: E.g., `image_resizer` or `slack_notify`.
    - **Description**: A clear explanation of what the tool does (e.g. "Use this tool to send a Slack message to the team channel").
    - **Parameters**: Define the input parameters the agent must provide (such as the target channel name and the message text).
    - **Script Code**: The automation script code uploaded by your administrator.
3.  Click **Save**.
4.  Navigate to **Agents** and check the box to assign this skill to your chosen Chat Agent.
