As your projects grow, finding the right media files quickly is critical. Shumai provides a powerful search dialog and flexible sorting controls.

---

## Searching Assets

Searching is performed inside a dedicated **Search Dialog** that you can open by clicking the search icon in the toolbar.

### Search Dialog Features

- **Keyword Matches**: Type a keyword in the text input to instantly filter file and folder names.
- **Advanced Filtering**: Click to expand the filters panel and build multi-conditional queries (e.g. searching for files where the custom field "Status" equals "In Progress" AND the file type is "Video").
- **Semantic Search Toggle**: If enabled by your team administrator, toggle "Semantic" on to search by conceptual meaning (e.g. searching "sunny beach" to find clips of oceans even if the filenames do not contain those words).
- **Save as Collection**: Easily convert your active search criteria into a dynamic folder. Click **Save as Collection** inside the dialog to create the collection and navigate to it instantly.
- **Infinite Scroll Results**: Search results load dynamically in real-time as you type or adjust filters.

## Sorting and Reordering Assets

You can change the sorting order of the asset list using the sort dropdown or by clicking metadata column headers:

- **Custom Sort (Default)**: By default, the project file explorer is set to **Custom** sorting. In this mode, you can manually drag and drop files and folders to reorder them exactly as you wish.
- **Standard Sort Options**: You can also sort files by:
  - _Newest Upload_: Displays recently uploaded assets first.
  - _Name_: Sorts alphabetically (A-Z or Z-A).
  - _Size_: Sorts by file size.
  - _Type_: Groups folders together at the top, followed by version stacks and individual files.
  - _Custom Columns_: Sorts by dynamic metadata fields (e.g., sorting by "Due Date" or "Priority").

> [!NOTE]
> **Drag and Drop Reordering Limit**: Drag-and-drop manual reordering is **only** available when the sort order is set to **Custom**. If you select any other sort option (such as Name or Size), manual reordering is disabled.
