As your projects grow, finding the right media files quickly is critical. Shumai provides search options and customizable sorting parameters.

---

## Searching Assets

The search bar at the top of the file explorer allows you to perform exact and partial keyword matches.

### Search Filters

- **Partial Matching**: Search matches any part of a file name as you type.
- **Recursive Search Toggle**: Choose whether to search only inside the **Current Folder** or search **Recursively** down the entire nested folder tree.
- **Asset Type**: Restrict your search to return only folders or only files.
- **Show Links**: Toggle whether virtual links (shortcuts to files in other projects or directories) should be displayed in your search results.

---

## Sorting Assets

You can sort your files by clicking the column headers or selecting a preference from the sort dropdown:

- **Newest Upload**: Lists the most recently uploaded files first (default).
- **Name**: Sorts alphabetically (A-Z or Z-A).
- **Size**: Sorts by file size.
- **Type**: Groups folders together followed by files and version stacks.
- **Custom Metadata Columns**: If your project has custom columns defined (such as "Due Date" or "Priority"), you can click those headers to sort the file list by these custom criteria.
