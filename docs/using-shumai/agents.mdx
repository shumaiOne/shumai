Shumai uses specialized AI Agents to perform background automation, chat workflows, and semantic indexing. Team Owners can create and manage multiple agents.

---

## Agent Types

Shumai supports three types of agents:

### 1. Chat Agent (`chat`)

An interactive, conversational bot that appears in your project workspace.

- You can start an active chat session with the agent inside any project.
- The agent is context-aware: it can read files, search the project folder, inspect metadata, and read comment threads.
- You can attach custom "Skills" to a chat agent, enabling it to write files, run scripts, or interact with external APIs on your behalf.

### 2. Autofill Agent (`autofill`)

A background agent that monitors file uploads.

- Once a file is uploaded, the Autofill Agent is triggered.
- It analyzes the file's content (multimodal images, text descriptions) and populates any metadata fields flagged for "AI Autofill".
- This is highly effective for automating tags, description summaries, camera settings, and video transcripts.

### 3. Embedding Agent (`embedding`)

A specialized utility agent that processes assets to generate vector embeddings.

- It runs embedding models (like OpenAI's `text-embedding-3-small` or local variants) on asset text, captions, or image descriptions.
- These vectors are saved in the `asset_embeddings` table to power Shumai's natural language semantic search capabilities.

---

## Configuring an Agent

To edit or create an agent, navigate to **Team Settings** > **Agents**:

- **Enabled / Disabled Toggle**: Stop or start the agent. If the embedding agent is disabled, semantic search indexing is paused.
- **System Prompt / Soul**: The core instructions that define the agent's behavior, guidelines, formatting requirements, and operational limits.
- **Model Provider**: Select which registered provider and model the agent should use for execution.
- **Assigned Skills**: Select which custom javascript skills this agent is permitted to execute.
